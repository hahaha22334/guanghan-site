# 广汉旅行书与堆堆 · 2026-10-11

八章旅行书从古蜀走向今日生活，末章连接已有路线与行程。桌面采用摄影与正文双页；手机按照片、正文的顺序呈现一章，可自然纵向滚动。目录、页角、按钮、左右方向键和照片区域横滑均可切章。青铜绿封皮、细金边、叠页纸边、中央书脊与书签构成书本外观。翻页采用本站自有 HTML/CSS 与 Web Animations：桌面双面书页围绕中央书脊正反翻动，手机整页揭开，配合轻微倾斜、起伏与动态阴影；分别约 860 / 720ms，无新增运行依赖。装饰副本移除 ID 和事件标记并设为 inert。快速操作累积到目标章；动画中切换普通阅读、调整窗口或关闭动态会清理临时书页。普通阅读与无脚本模式连续展开所有章节；正文无固定高度裁切。系统减少动态或护照中的动态开关关闭时，切章直接完成。

`content/book.json` 维护精选叙事，事实与出行原文仍在统一地点/路线数据和详情页。目录、导航、首页入口和 sitemap 都可进入 `book.html`。章节 hash 用于分享；`guanghan-book-v1` 仅记录合法章节 ID 与普通阅读偏好。

翻页按钮与简洁章数放在书上缘的吸顶工具栏中，阅读长页时仍可操作；桌面书页最小高度随视口调整。翻页、页角、方向键及横滑保留当前滚动位置，不再自动回到书顶。只有普通阅读中主动选择目录时才滚动到对应章节；普通阅读隐藏翻页工具栏。

本站原创向导暂名堆堆。九张由站主提供的透明精灵图对应 idle / wave / pet / hop / think / talk / point / stamp / sleep，各十六帧。2026-10-11 新原图为 1254×1254；由于生成图各行并不等高，`prepare-pet.js` 按连通轮廓分离十六个角色，统一原像素缩放比例与落脚基准、保留透明度，并为 hop 添加起落轨迹；不重绘或拉伸角色。打包为 1024×1024 WebP，四列四行逐行播放。单个动作约 217–247KB，按需解码，首次仅加载待机与欢迎。使用时间驱动的 requestAnimationFrame，各动作每帧 75–110ms，完整播放后回待机。空闲 1.8–4.2 秒后，从眨眼、招手、被摸头、小跳、翻手记中随机挑选下一动作，避免连续重复；对话框开启时暂停随机动作，用户操作优先。页面隐藏、系统减少动态与用户动态开关均停止循环，恢复后回到正常待机。休息动作播完才收起为“唤醒堆堆”，偏好保存在 `guanghan-pet-v1`，跨页保持。不会自动弹问答或播放声音。

公共入口在所有十四个内容页右下角。手机避开详情页底部操作栏；原悬浮护照在向导正常启动后收进菜单，脚本故障时保留原入口。问答使用原生 dialog；Escape 关闭，关闭后焦点回入口。护照页标题区也显示小鸟，使盖章反馈在弹窗里可见。

第一层问答完全本地运行，匹配约二十类常用意图与七地点资料。知识库由 `scripts/build-companion.js` 从 guide/travel 数据生成，别名与表达规则在 `companion-logic.js`。回答展示匹配问题、资料文字、原文入口与整理日期；不保存提问、不调用模型、不传输问题。未知问题提供目的地和问答入口。实时票务、车次与花情优先显示核验说明，不生成即时状态。

问答操作只允许打开阅读护照或添加合法地点，跳转地址来自整理资料。加入行程复用现有 `data-add-trip` 处理，雒城/房湖继续按同一联游组合并。阅读章仍分别对应七地点，书中的雒城与房湖可各盖一枚；记录阅读，不代表实际到访。书页通过 `guanghan:passportopen` 传入地点与用户主动盖章意图，护照使用原来的存储和校验，未创建第二份印章数据。
