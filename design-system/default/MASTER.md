# 广汉三千年之旅 · 设计系统

> 全站视觉与交互的单一事实来源。页面级规则仅在 `pages/` 中明确覆盖时生效。

## 1. 产品方向

- **叙事主线**：一日穿越三千年；三星堆 → 雒城 / 房湖 → 老城街巷 → 非遗美食。
- **体验目标**：先帮助访客选路线和安排行程，再提供历史背景；详情页必须是可操作的出行工具。
- **视觉关键词**：古蜀档案感、川西生活感、克制、可读、在地。
- **避免**：百科栏目堆叠、自动轮播、泛金色渐变、悬浮卡片海洋、过度圆角、境外字体或图标 CDN。

## 2. 设计令牌

以 `assets/css/tokens.css` 为执行标准：

| 角色 | 颜色 | 用途 |
|---|---|---|
| 青铜深绿 | `#17362e` / `#29483e` | 导航、深色段落、主要按钮 |
| 青铜绿 | `#567266` / `#87a095` | 次级图形、地图、分隔信息 |
| 氧化金 | `#a77b22` / `#d7bf7b` | 时间标记、重点、焦点环 |
| 陶土米色 | `#f7f2e6` / `#e9dfc9` | 档案纸张感背景与分区 |
| 正文 | `#202a26` / `#55615c` | 标题与正文 |

- 正文与背景对比至少 4.5:1；焦点环始终可见。
- 圆角只用于小范围分组，默认 4–10px；按钮可使用胶囊形。
- 阴影保持轻微，优先使用边框、留白和色面建立层级。

## 3. 字体与图标

- 标题：`Songti SC` / `STSong` / `SimSun` 系统宋体回退。
- 正文：`Microsoft YaHei` / `PingFang SC` / `Noto Sans CJK SC` / `system-ui`。
- 不加载 Google Fonts、Font Awesome 或其他 CDN。
- 图标统一来自 `assets/icons.svg`，同一视觉层使用相同描边；装饰图标设 `aria-hidden="true"`。

## 4. 布局与组件

- 移动优先；核心断点为 768px、1024px，最大内容宽度 1200px。
- 首页使用单一主视觉、三条路线入口、四段纵向旅程和末端行动入口。
- 详情页统一包含：面包屑、主视觉、四项行程事实、页内目录、历史脉络、现场看点、建议顺序、出行核验、前后站点。
- 移动端底部操作栏最多三项：回到路线、地图导航、官方或出行信息；正文必须预留安全区。
- V2 图片叙事使用三类可复用构图：`editorial-atlas`（首页一主三辅城市切片）、`archive-essay`（横幅—肖像组三联—收束横幅的文物档案）、`cinematic-diptych` / `visual-journal` / `season-sequence`（按路线顺序组织的宽窄对照与季节序列）。它们在移动端均按语义 DOM 顺序回落为单列，不改写阅读顺序。
- 图片叙事优先用留白、比例、细边框和版面跨度建立节奏，不把每张图处理成同等权重的圆角卡片；不使用轮播、灯箱、视差或滚动劫持。
- 所有触控目标至少 44×44 CSS px；不得依赖 hover 才能完成主要操作。

## 5. 图片与素材

- 本地图片使用 `<picture>`，优先 AVIF → WebP → 原图；只声明实际存在的变体。
- 首屏图 `loading="eager"` + `fetchpriority="high"`；其余图片 lazy load。
- 每张 `<img>` 写明 `width`、`height` 和语义准确的 `alt`，避免 CLS 与图文错配。
- 新媒体通过 `.asset-sources.json` 留存来源台账；台账不得复制进公开 `dist/`。
- `images/external/` 中获批导入素材必须登记在 `optimize-images.js` 的显式清单：1080px 宽肖像只生成 400w/800w，足够宽的横幅才生成 1200w/1600w，HTML 不得声明源图未生成的宽度。
- 不去水印、不引用远程素材 URL，不使用未经站点所有者选择的候选素材。

## 6. 动效与无障碍

- 页面在 JavaScript 关闭时仍完整可读；渐入只使用 `opacity` 和 `transform`。
- `prefers-reduced-motion: reduce` 下禁用非必要动画与平滑滚动。
- 六页均提供 skip link、语义化 `main`、顺序标题、键盘菜单、可见焦点、准确 alt。
- 外链新窗口必须带 `rel="noopener noreferrer"`；动态状态通过 `aria-live` 低打扰播报。

## 7. SEO 与发布

- 每页具有独立 title、description、canonical、Open Graph 与可信字段的 JSON-LD。
- 动态票务、开放、班次、活动和花期不得写成永久承诺，统一提示临行核验。
- 发布前必须运行 `npm test` 与 `npm run build`；只部署 allowlist 生成的 `dist/`，禁止公开 `.asset-sources.json`、设计文档、脚本与缓存。
